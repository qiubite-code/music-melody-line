功能主要用途基本操作

      
实时旋律可视化查看演唱或音频的旋律线、音高和音准。录音或上传音频 → 播放观察 → 生成报告。

      
节奏创编组合节奏型，训练多声部节奏。选择素材 → 拖入轨道 → 试听/删除。

      
旋律创编用钢琴卷帘或简谱小键盘创作旋律。选调号、节奏、音高 → 试听 → 生成旋律线。

      
音阶调式生成器生成全球常用音阶、中国民族调式、日本调式、印度拉格、非洲音阶、爵士与布鲁斯音阶等。选地域、主音和调式 → 查看音名/键盘 → 试听音阶。

      
智能跟弹与和弦连接 MIDI 键盘，导入 MIDI/XML，显示下落音符与和弦分析。连接键盘或导入文件 → 播放/跟弹 → 查看和弦名称、组成音、转位和功能。

      
乐器调音器用麦克风识别音高，对常见乐器和民族乐器进行调弦。选择乐器与调弦 → 开启麦克风 → 看指针调到中心。

      
和弦编配为旋律快速配置和弦伴奏。点小节 → 选和弦 → 播放和弦或旋律+和弦。

      
节拍器与节拍测速器训练速度、拍号、强弱拍，并通过连续点击测算音乐 BPM 与术语速度。设置 BPM/拍号 → 开始节拍器 → 在测速器中连续点击按钮测算速度。

      
作品保存保存课堂创作结果。保存当前作品 → 读取或导出 JSON。
