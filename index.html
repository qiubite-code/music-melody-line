实时音频旋律线条可视化系统

作者：丘比特

面向中小学 / 初中音乐课堂：麦克风拾音或上传 mp3、wav 后，系统会把音高、力度、节奏、休止、乐句转换为可观察的线条。适合演唱示范、乐句分析、旋律走向比较和课堂即时反馈。

音高 / 旋律Y 轴上下变化：高音上移，低音下沉。
力度 / 音量线条粗细与透明度：强音更粗、更实。
节奏 / 节拍按真实时间横向推进：快节奏图形更密集。
休止 / 乐句低于阈值断线留白，长停顿自动标记乐句。
提示先点击“开启麦克风”进行实时演唱，或上传音频后点击播放器播放。麦克风在多数浏览器中需要 HTTPS 或 localhost 环境。

教学读图法：线条上扬表示旋律上行，下沉表示旋律下行；粗线多为强音，细线多为弱音；断开留白表示休止或换气；虚线表示系统依据停顿自动识别的乐句分隔。

作者：丘比特｜课堂建议：先让学生闭眼聆听，再观察线条，最后用“上行 / 下行 / 平行 / 强弱 / 停顿 / 乐句”描述音乐结构。系统采用浏览器端分析，不上传学生声音。
